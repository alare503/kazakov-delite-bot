# Anti-Delete Telegram Bot

Бот уведомляет подписчика, если кто-то **удалил** или **изменил** сообщение в группе.

---

## Быстрый запуск (без командной строки)

В папке проекта лежат готовые файлы-запускалки. Просто **двойной клик**:

| Файл | Что делает |
|------|-----------|
| `install.bat` | Установить библиотеки (первый раз, один раз) |
| `get_token.bat` | Получить токен ЮMoney |
| `start_bot.bat` | Запустить бота |

Ничего в консоли печатать не нужно — только вставлять то, что просят (client_id, ссылку из браузера).

---

## Что нужно сделать перед запуском

Всего 4 шага:
1. Создать бота в Telegram
2. Узнать свой Telegram-ID
3. Настроить приём платежей через ЮMoney
4. Настроить и запустить бота на компьютере

---

## Шаг 1. Создание бота в Telegram

1. Открой Telegram, найди **@BotFather** (это официальный бот).
2. Напиши ему: `/newbot`
3. Введи любое имя бота, например: `Anti-Delete Bot`
4. Введи username бота (должен заканчиваться на `bot`), например: `antidelete_moi_bot`
5. BotFather пришлёт тебе **токен** — длинную строку вида `123456789:AA...`
   - Скопируй и сохрани — он понадобится в `.env`

---

## Шаг 2. Узнать свой Telegram-ID

1. В Telegram найди **@userinfobot**
2. Напиши ему любое сообщение
3. Он ответит твоим ID (число) — сохрани.

---

## Шаг 3. Настройка ЮMoney

### 3.1. Создай кошелёк ЮMoney (если ещё нет)

1. Зайди на https://yoomoney.ru/reg
2. Зарегистрируйся / войди под существующим аккаунтом
3. Номер кошелька виден в приложении/на сайте — длинное число вида `4100117xxxxxxxxx`
   - Это и есть твой `YOOMONEY_WALLET`

### 3.2. Создай приложение для получения токена

1. Зайди на https://yoomoney.ru/myservices/new (логинясь из своего кошелька)
2. Заполни:
   - **Название для пользователей:** любое (например: `AntiDeleteBot`)
   - **Веб-адрес:** `https://example.com` (любой настоящий сайт. Свой username бота сюда НЕ пиши)
   - **Email:** твой email
   - **Redirect URI:** `https://example.com/` (это просто адрес «куда вернуться» после подтверждения, localhost ЮMoney не принимает)
   - **Notification URI / URL уведомлений:** оставить ПУСТЫМ
   - **Галочку «Проверять подлинность приложения»** — **ОСТАВЬ СНЯТОЙ**
3. Нажми **«Подтвердить»**
4. На следующей странице появится `client_id` — длинная строка. Скопируй его.

### 3.3. Получи токен (access_token)

#### Простой способ — через скрипт:

```bash
python get_token.py
```
Скрипт:
- Спросит `client_id` — вставь из шага 3.2
- Спросит Redirect URI — вставь то же самое из настроек приложения (`https://example.com/`)
- Покажет ссылку — открой её в браузере (логинясь из своего кошелька)
- Нажми «Подтвердить доступ»
- Браузер перейдёт на `https://example.com/?code=...` — страница может не загрузиться, **это нормально**
- Скопируй из адресной строки браузера ВСЮ ссылку (`https://example.com/?code=XXXXXXX`) и вставь её в скрипт
- Скрипт обменяет код на токен и выведет `YOOMONEY_TOKEN=41001...`

#### Альтернатива — вручную:

1. Открой в браузере (логинясь из кошелька), подставив свой client_id:
   ```
   https://yoomoney.ru/oauth/authorize?client_id=СЮДА_ВСТАВЬ_CLIENT_ID&response_type=code&redirect_uri=https%3A%2F%2Fexample.com%2F&scope=account-info%20operation-history%20operation-details
   ```
2. Подтверди доступ. Браузер перенаправит на `https://example.com/?code=XXXXXXX`
3. Скопируй `XXXXXXX` (значение `code`)
4. Выполни в терминале (замени `XXXXXXX` на свой код, `СЮДА_ВСТАВЬ_CLIENT_ID` на свой client_id):
   ```bash
   curl -X POST https://yoomoney.ru/oauth/token -d "code=XXXXXXX&client_id=СЮДА_ВСТАВЬ_CLIENT_ID&grant_type=authorization_code&redirect_uri=https://example.com/"
   ```
   В ответе будет JSON с полем `access_token` — это и есть твой `YOOMONEY_TOKEN`.

## Шаг 4. Запуск бота

### 4.1. Убедись, что установлен Python 3.10+

Открой терминал и введи:
```bash
python --version
```
Если выдаёт ошибку — скачай Python с https://www.python.org/downloads/ (при установке поставь галочку "Add Python to PATH").

### 4.2. Установи зависимости

В папке проекта выполни:
```bash
pip install -r requirements.txt
```

### 4.3. Отредактируй файл `.env`

Открой файл `.env` в любом текстовом редакторе (Блокнот) и заполни:

```
BOT_TOKEN=123456789:AAГГГ... (токен от BotFather, шаг 1)
BOT_USERNAME=antidelete_moi_bot (username бота без @, шаг 1)
ADMIN_ID=516481920 (твой Telegram ID, шаг 2)
YOOMONEY_TOKEN=41001234... (токен ЮMoney, шаг 3.3)
YOOMONEY_WALLET=4100117... (номер твоего кошелька ЮMoney, шаг 3.1)
DB_PATH=messages.db
```

### 4.4. Запусти бота

```bash
python bot.py
```

В консоли появится `INFO:... Бот запущен!` — бот работает.

Чтобы бот работал постоянно — оставь терминал открытым. Чтобы закрыть — нажми `Ctrl+C`.

## Как пользоваться (для клиентов)

1. Клиент находит бота в Telegram, жмёт **Start** или пишет `/start`
2. Пишет `/subscribe` → видит кнопку **«Оплатить 100 ₽»**
3. Нажимает кнопку → открывается платёжная страница ЮMoney
4. Оплачивает 100 ₽ с банковской карты
5. Возвращается в бота → жмёт **«Я оплатил — проверить»**
6. Бот автоматически проверяет по API ЮMoney, видит платёж и выдаёт подписку
7. Клиент добавляет бота в нужный чат **администратором** (важно!)
8. Готово — бот следит за удалёнными/изменёнными сообщениями

### Уведомления приходят в бот (личку), например:

- **Удаление:**
  ```
  🗑 Удалённое сообщение...

  Привет всем!

  👤 @ivan удалил сообщение.
  ```

- **Редактирование:**
  ```
  ✏️ Изменённое сообщение...

  Исходное сообщение:
  Встретимся в 5

  Изменённое сообщение:
  Встретимся в 6

  👤 @ivan изменил сообщение.
  ```

## Команды бота

| Команда      | Что делает                                        |
|-------------|--------------------------------------------------|
| `/start`    | Знакомство с ботом                               |
| `/subscribe`| Купить подписку                                  |
| `/status`   | Проверить статус подписки и дату окончания       |
| `/mychats`  | Список чатов, где работает бот                   |
| `/give ID`  | *(админ)* Ручная выдача подписки                 |

---

## Важно

- **Бот должен быть администратором** в чате, иначе Telegram не присылает события об удалении/редактировании
- Бот уведомляет **только владельца подписки** (не всех участников чата)
- Если ЮMoney не нашёл платёж (нечастая проблема) — оплата может проходить с задержкой до нескольких минут. Напиши в бот команду `/give <id>`, чтобы выдать подписку вручную.
- Токен ЮMoney действителен **3 года**. По истечении придётся повторить шаг 3.3.
- Не поделивайся файлом `.env` — там твои ключи доступа к боту и ЮMoney
